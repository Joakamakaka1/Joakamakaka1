# Icons

Copied into the repository so the profile does not depend on an external icon service.

- Most icons are the dark variants from [LelouchFR/skill-icons](https://github.com/LelouchFR/skill-icons) (MIT, see `LICENSE-skill-icons`).
- `bedrock.svg`, `langgraph.svg` and `langfuse.svg` wrap logos from [lobehub/lobe-icons](https://github.com/lobehub/lobe-icons) (MIT, see `LICENSE-lobe-icons`) in the same dark frame.
- `neuraltrust.svg` wraps the official NeuralTrust mark (from the NeuralTrust docs) in the same frame.
- `aisdk.svg` is the Vercel triangle with an "AI SDK" label in the same frame.

All logos are trademarks of their owners and are used only to name the technologies.
